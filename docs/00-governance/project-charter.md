# Project Charter

## Nombre provisional
MU Online Season 4 Knowledge & Build Planner.

## Problema
La información técnica de MU Online está fragmentada, mezcla temporadas y suele omitir la fórmula, el orden de aplicación, los redondeos o las modificaciones de servidores privados. Esto dificulta planificar builds y validar resultados.

## Visión
Crear una fuente técnica única, verificable y explicable para Season 4 global/inglesa, con una calculadora modular capaz de representar tanto reglas estándar como perfiles personalizados.

## Objetivos
- Centralizar conocimiento técnico versionado.
- Permitir simulación de personajes y builds.
- Mostrar la trazabilidad de cada resultado.
- Evitar datos inventados o mezclas silenciosas de temporadas.
- Facilitar mantenimiento humano y mediante IA.

## Restricciones
- No se codificará una fórmula no verificada como comportamiento estándar.
- Las variaciones de servidores privados deberán vivir en perfiles, no como excepciones ocultas.
- El proyecto no dependerá de scraping en tiempo de ejecución para funcionar.
- Las fuentes externas no se copiarán sin respetar licencias y atribución.

## Éxito
El producto se considera exitoso cuando un usuario puede crear un personaje, configurar nivel/quests/resets, distribuir puntos, equiparlo, obtener resultados explicados y reproducibles, y comparar builds bajo un perfil de servidor explícito.
