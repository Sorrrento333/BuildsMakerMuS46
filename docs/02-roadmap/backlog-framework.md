# Marco de backlog

## Formato de épica
- Objetivo.
- Valor para usuario.
- Alcance/no alcance.
- Dependencias.
- Riesgos.
- Criterio de salida.

## Formato de historia
`Como <rol>, quiero <capacidad>, para <beneficio>.`

Debe incluir:
- criterios de aceptación Given/When/Then;
- datos/fórmulas afectados;
- pruebas requeridas;
- documentación a actualizar;
- impacto de migración.

## Prioridad
- P0: bloquea exactitud o continuidad.
- P1: necesario para el siguiente hito.
- P2: mejora importante.
- P3: futuro.

## Etiquetas
`domain`, `research`, `formula`, `data`, `frontend`, `backend`, `qa`, `docs`, `security`, `migration`, `decision-needed`.
