# Definition of Done

Una tarea está terminada cuando:
- cumple criterios de aceptación;
- tiene pruebas apropiadas;
- no reduce calidad crítica;
- actualiza schemas/datos si corresponde;
- actualiza documentación y changelog;
- incluye provenance para datos/fórmulas;
- pasa CI;
- no deja decisiones implícitas;
- actualiza estado y siguientes acciones si cambia el rumbo del proyecto.
