# Estándares de código

- Tipado estricto.
- Funciones de cálculo puras siempre que sea posible.
- Nombres de dominio en inglés en código; documentación de usuario en español inicialmente.
- Sin números mágicos: usar reglas versionadas.
- Errores de dominio tipados.
- Logs sin datos personales innecesarios.
- Comentarios explican por qué, no repiten qué hace el código.
- Cada PR pequeña, con issue, pruebas y docs.
- Formateador, linter y análisis estático automáticos.
- Dependencias fijadas y revisadas.
