# Casos de uso

## UC-01 Crear personaje
El usuario elige perfil, clase y evolución. El sistema carga stats base, restricciones y reglas de puntos.

## UC-02 Calcular puntos disponibles
El usuario informa nivel, quests, resets y parámetros. El sistema desglosa puntos base, por nivel, por quest, por reset, gastados y restantes.

## UC-03 Distribuir estadísticas
El usuario asigna Strength, Agility, Vitality, Energy y Command cuando corresponda. El sistema impide valores inválidos y actualiza resultados.

## UC-04 Equipar ítems
El usuario elige ranura, ítem, nivel y opciones. El sistema valida clase, requisitos, exclusiones y bonificaciones.

## UC-05 Explicar resultado
El usuario abre una cifra. El sistema muestra fórmula, sustitución de valores, redondeos, modificadores, versión y fuentes.

## UC-06 Comparar builds
El usuario selecciona dos builds y un escenario. El sistema muestra diferencias absolutas, porcentuales, breakpoints y advertencias.

## UC-07 Crear perfil de servidor
Un administrador clona un perfil, modifica reglas permitidas, valida el esquema y lo exporta.

## UC-08 Investigar fórmula
Un investigador registra hipótesis, fuentes, pruebas y resolución; solo una revisión aprobada puede elevarla a VERIFIED.
