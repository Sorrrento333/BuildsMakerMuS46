# Mapa de módulos

- `rulesets`: paquetes de reglas por versión.
- `characters`: clases, evoluciones y stats.
- `progression`: niveles, quests y resets.
- `formulas`: definiciones y evaluación.
- `modifiers`: buffs, equipo, opciones y efectos.
- `items`: catálogo, requisitos y mejoras.
- `builds`: composición, validación y persistencia.
- `scenarios`: contexto PvM/PvP.
- `comparison`: diferencias y breakpoints.
- `encyclopedia`: consulta y búsqueda.
- `profiles`: personalización de servidores.
- `provenance`: fuentes, evidencia y confianza.
- `imports`: ingestión y normalización.
- `audit`: trazas, cambios y diagnósticos.

Cada módulo publica contratos y no accede directamente a tablas de otro módulo.
