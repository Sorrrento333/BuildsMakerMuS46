# Mantenimiento

## Rutinas
- Revisar issues de datos y fórmulas.
- Revalidar enlaces y snapshots de evidencia.
- Actualizar dependencias con pruebas.
- Auditar conflictos abiertos.
- Ejecutar regresión completa antes de release.
- Confirmar que documentación de traspaso refleja el estado real.

## Deprecación
Nunca eliminar silenciosamente reglas o campos. Marcar, migrar, mantener compatibilidad durante una ventana definida y documentar reemplazo.
