# Guía de contribución

1. Elegir o crear issue.
2. Leer documentos del módulo.
3. Para datos/fórmulas, crear registro de investigación.
4. Implementar cambio pequeño y probado.
5. Actualizar documentación.
6. Abrir PR con motivación, evidencia, impacto y rollback.

Las contribuciones que solo agreguen cifras sin provenance no serán aceptadas.

## Licencia de contribuciones

Salvo que se declaren explícitamente como `Not a Contribution`, los cambios
enviados intencionalmente para incorporarse al proyecto se ofrecen bajo Apache
License 2.0, conforme a la sección 5 de la licencia y ADR-0005. Quien contribuye
debe tener autoridad para aportar el material y no debe incluir contenido de
terceros sin permiso, atribución y condiciones de uso registradas.
