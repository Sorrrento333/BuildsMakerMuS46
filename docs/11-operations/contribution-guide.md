# Guía de contribución

1. Elegir o crear issue.
2. Leer documentos del módulo.
3. Para datos/fórmulas, crear registro de investigación.
4. Implementar cambio pequeño y probado.
5. Actualizar documentación.
6. Abrir PR con motivación, evidencia, impacto y rollback.

Las contribuciones que solo agreguen cifras sin provenance no serán aceptadas.
