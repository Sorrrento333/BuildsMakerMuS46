# Licencia del proyecto

Pendiente de decisión del propietario. El repositorio es públicamente visible
desde el 2026-07-19 por decisión del propietario, pero esta visibilidad no concede
permiso para usar, copiar, modificar o redistribuir el contenido. No reutilizar
externamente hasta seleccionar una licencia explícita.

Opciones recomendadas:
- MIT para máxima reutilización.
- Apache-2.0 para incluir concesión de patentes.
- Propietaria para distribución restringida.

La elección debe registrarse como ADR antes de publicar una release o promover
reutilización externa.
