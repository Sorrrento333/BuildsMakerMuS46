# Licencia del proyecto

Pendiente de decisión del propietario. No publicar ni reutilizar externamente hasta seleccionar una licencia.

Opciones recomendadas:
- MIT para máxima reutilización.
- Apache-2.0 para incluir concesión de patentes.
- Propietaria para distribución restringida.

La elección debe registrarse como ADR antes de la primera publicación pública.
